# 콘텐츠 관리 (library)

원본: PRD v0.5 §4.5, §5.3~5.5 · 공통 규칙: [architecture §4 상태](../architecture.md#4-콘텐츠의-공통-상태)

## 1. 목적

요약을 보고 내린 결정대로 중요한 것은 보관하고 불필요한 것은 제거하게 한다. **정리를 강요하지 않는다** — Inbox는 비우지 않아도 쌓이지 않는다.

## 2. 범위

**P0 포함**

| ID | 요구사항 |
| --- | --- |
| LIB-1 | 전체 콘텐츠 목록을 보고 검색·정렬한다(최근순·오래된 순). 저장일·출처·추출 수준을 확인한다 |
| LIB-2 | Inbox: 새로 저장한 콘텐츠가 들어온다. 30일이 지나면 자동으로 보관됨으로 이동한다 |
| LIB-3 | 보관함: 사용자가 유지하기로 했거나 30일이 지난 콘텐츠. 검색과 재노출 대상이다 |
| LIB-4 | 휴지통: 삭제한 콘텐츠. 복구할 수 있고 30일 후 영구 삭제된다 |
| LIB-5 | 콘텐츠에 한 줄 메모를 단다. 메모는 검색 대상이다 |
| LIB-6 | 가져온 폴더별로 필터한다 |
| LIB-7 | 정리 화면: 링크 소멸 콘텐츠의 일괄 삭제를 제안한다. 가져오기 직후 진입을 유도한다 (범위는 D-01) |
| LIB-8 | 여러 콘텐츠를 골라 일괄 처리한다(보관·삭제) |

**제외 (P1)**

출처별 필터, 태그, 사용자 폴더, 중복·유사 콘텐츠 정리, 오래된 콘텐츠 일괄 정리 추천.

## 3. 플랫폼별 역할

| 플랫폼 | 역할 |
| --- | --- |
| 서버 | 목록·상태 변경·메모·일괄 처리 API |
| 워커 | Inbox 30일 자동 보관, 휴지통 30일 영구 삭제 |
| 웹 | Inbox, 보관함, 휴지통, 정리 화면, 메모 편집, 일괄 처리 |
| 모바일 | Inbox, 보관함, 기본 관리 액션 **[확인 필요: 모바일에서 정리 화면·일괄 처리까지 제공할지 원문에 없다]** |
| 확장 | 없음 |

## 4. 화면

| 화면 | 내용 |
| --- | --- |
| Inbox | 최근 30일 내 저장한 콘텐츠, 요약, 보관·나중에 보기·삭제, 일괄 관리 |
| 보관함 | 전체 보유 콘텐츠, 최근순·오래된 순 정렬, 가져온 폴더별 필터, 선택 콘텐츠 관리 |
| 정리 | 일괄 삭제·보관 제안 (D-01) |

## 5. 동작 규칙과 예외

**보관 상태**

| 상태 | 설명 |
| --- | --- |
| Inbox | 새로 저장한 콘텐츠. 30일이 지나면 자동으로 보관됨으로 이동 |
| 보관됨 | 사용자가 유지하기로 했거나 30일이 지난 콘텐츠 |
| 휴지통 | 삭제한 콘텐츠. 30일 후 영구 삭제 |

**링크 소멸**은 보관 상태가 아니라 어느 상태에나 겹쳐 붙는 플래그다. 전이 규칙은 [architecture §4](../architecture.md#4-콘텐츠의-공통-상태).

- Inbox 자동 보관은 정리를 강요하지 않기 위한 장치다. 자동 보관은 사용자에게 알리거나 확인을 요구하지 않는다.
- 일괄 삭제도 휴지통으로 간다(복구 가능).
- §5.4는 보관함을 "전체 보유 콘텐츠"로 적는다. 보관함 화면이 Inbox 콘텐츠까지 보여주는지, 보관됨 상태만 보여주는지는 **[확인 필요]** 다. LIB-1의 "전체 콘텐츠 목록"과 같은 화면인지도 포함된다.

## 6. 완료 조건

- [ ] 새로 저장한 콘텐츠가 Inbox에 나타난다.
- [ ] 저장 후 30일이 지난 Inbox 콘텐츠는 사용자 조작 없이 보관됨이 된다(시간을 주입한 테스트로 보인다).
- [ ] 보관·삭제·복구가 동작하고, 복구한 콘텐츠가 휴지통에서 사라진다.
- [ ] 삭제 후 30일이 지난 콘텐츠는 영구 삭제되어 목록·검색 어디에도 나오지 않는다.
- [ ] 메모를 저장하면 그 단어로 검색된다.
- [ ] 가져온 폴더를 고르면 그 폴더의 콘텐츠만 나온다.
- [ ] 여러 콘텐츠를 골라 한 번에 보관·삭제할 수 있다.
- [ ] 정리 화면에 링크 소멸 콘텐츠가 모여 나오고 한 번에 삭제할 수 있다.
- [ ] 목록의 각 콘텐츠에 저장일·출처·추출 수준이 보인다.
- [ ] 최근순·오래된 순 정렬이 동작한다.
- [ ] 계측: 보관, 삭제, 정리 화면 진입·일괄 삭제가 기록된다 (가져오기 후 정리 화면 사용률, 정리 성공).
