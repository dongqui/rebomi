# 주기적 재노출 (resurfacing)

원본: PRD v0.5 §2.2 시나리오 A, §4.4, §5.1, §5.6, §10(재노출 지표), §11.4, §13 H2·H5 · 공통 규칙: [architecture §4 상태](../architecture.md#4-콘텐츠의-공통-상태), [§6 재노출의 책임](../architecture.md#6-재노출의-책임)

## 1. 목적

**제품의 핵심 차별점이다.** 저장한 콘텐츠를 다시 확인하고 활용할 기회를 준다. 읽기를 강요하지 않고, 잊은 것을 떠올리게 하는 데 집중한다.

## 2. 범위

**P0 포함**

| ID | 요구사항 |
| --- | --- |
| RES-1 | 규칙 기반으로 저장된 콘텐츠 중 일부를 일정 주기로 선정한다 (§5 선정 규칙) |
| RES-2 | 재노출 대상 풀을 보관 상태와 별도로 관리한다. 출처별 기본값이 다르다 (§5 대상 풀) |
| RES-3 | 사용자가 풀을 바꿀 수 있다: 콘텐츠별 "재노출 중단"·포함, 가져온 폴더 단위 포함, 보관됨 포함 여부 설정 |
| RES-4 | 홈 화면에 재노출 콘텐츠를 카드형으로 보여준다 (3~5개). 홈의 중심이다 |
| RES-5 | 카드에서 처리할 수 있다: 원문 열기, 나중에 다시 보기, 보관하기, 재노출 중단, 삭제하기 |
| RES-6 | 사용자별 재노출 빈도를 설정한다. 한 번에 끌 수 있다 |
| RES-7 | 동의한 경우 모바일 푸시로 알린다 (제공 대상은 D-02) |

**제외 (P1)**

관심사 기반 재노출, 검색 주제 관련 자료 재노출, 주간 이메일 다이제스트, 재노출 날짜 직접 지정, 행동 기반 추천 최적화.

## 3. 플랫폼별 역할

| 플랫폼 | 역할 |
| --- | --- |
| 워커 | 주기 실행, 회차 선정·저장, 푸시 발송 |
| 서버 | 선정 규칙(`core`), 홈 피드·액션·설정 API, 노출·액션 이벤트 기록 |
| 웹 | 홈 재노출 피드, 카드 액션, 재노출 설정 |
| 모바일 | 홈 재노출 피드, 카드 액션, 재노출 설정, 푸시 수신·권한 동의 |
| 확장 | 없음 |

## 4. 사용자 흐름

1. 저장하고 시간이 지나면 홈에 "오늘의 재노출" 카드가 나타난다(동의했다면 푸시도).
2. 카드를 펼쳐 요약을 확인한다.
3. 원문을 열거나, 나중에 다시 보거나, 보관하거나, 재노출을 중단하거나, 삭제한다.
4. 설정에서 빈도와 대상(보관됨 포함, 가져온 폴더 선택)을 바꾼다.

## 5. 동작 규칙과 예외

**대상 풀**

| 콘텐츠 출처·상태 | 기본값 | 변경 방법 |
| --- | --- | --- |
| 확장·모바일·웹에서 직접 저장 | 포함 | 콘텐츠별 "재노출 중단" |
| 북마크 가져오기 | 제외 | 가져온 폴더 단위로 포함, 또는 콘텐츠별 포함 |
| 보관됨 | 설정에 따름 (기본 포함) | 설정에서 끄기 |
| 링크 소멸 | 제외 | 변경 불가 |

**[제안] 겹칠 때의 우선순위** — 원문에 없다. 가져온 콘텐츠가 30일 뒤 자동 보관되면 "가져오기=제외"와 "보관됨=기본 포함"이 겹친다. 제안: ① 링크 소멸·휴지통이면 제외 ② 콘텐츠별 명시 설정(중단/포함)이 있으면 그것 ③ 가져온 콘텐츠는 폴더 포함 설정 ④ 그 밖에는 출처 기본값, 보관됨이면 설정값. 재노출 선정 Issue의 설계에서 확정한다.

**선정 기준 (규칙 기반) — 모두 만족해야 후보다**

- 저장한 지 7일 이상 지났다
- 이전 재노출 이후 14일 이상 지났다
- 최근 7일 내 사용자가 확인하지 않았다
- 삭제·재노출 중단·링크 소멸이 아니다
- 같은 회차에 같은 도메인이 2개를 넘지 않는다

**초기 기본 설정:** 주 2~3회, 회당 3~5개, 홈 화면 표시, 동의한 경우 모바일 푸시. 정확한 값은 D-05.

**그 밖의 규칙**

- 최근 확인한 자료는 반복하지 않는다.
- 원문을 열었다는 이유만으로 읽기를 완료했다고 단정하지 않는다. 원문 열기는 콘텐츠를 풀에서 빼지 않는다.
- 보관하기는 보관 상태만 바꾼다. 재노출 포함 여부는 설정을 따른다.
- 삭제와 재노출 중단은 "재활용"이 아니라 "정리 성공"으로 센다.
- 피로도 대응: 낮은 기본 빈도, 가져온 콘텐츠 기본 제외, 도메인 다양성, 한 번에 끄는 설정.

## 6. 완료 조건

- [ ] 선정 규칙이 순수 함수로 구현되어, 다섯 기준 각각을 어기는 후보가 선정되지 않음을 단위 테스트로 보인다.
- [ ] 직접 저장한 콘텐츠는 기본으로 후보가 되고, 가져온 콘텐츠는 폴더를 포함시키기 전까지 후보가 아니다.
- [ ] 링크 소멸 콘텐츠는 어떤 설정으로도 선정되지 않는다.
- [ ] "재노출 중단"한 콘텐츠는 다시 선정되지 않는다.
- [ ] 한 회차에 같은 도메인이 3개 이상 들어가지 않는다.
- [ ] 홈에 재노출 카드가 표시되고 다섯 액션이 각각 동작한다.
- [ ] 빈도 설정을 바꾸면 다음 회차부터 반영되고, 끄면 선정과 푸시가 모두 멈춘다.
- [ ] 보관됨 포함을 끄면 보관됨 콘텐츠가 선정되지 않는다.
- [ ] 푸시 권한에 동의하지 않은 사용자에게는 푸시가 가지 않는다.
- [ ] 후보가 모자랄 때 D-05에서 정한 대로 동작한다(오류 없이).
- [ ] 계측: 노출, 카드 펼침, 펼친 뒤 체류 시간, 각 액션, 알림 해제, 빈도 변경이 기록된다. 재노출된 콘텐츠와 그렇지 않은 콘텐츠의 원문 열람을 비교할 수 있다 (H2).
