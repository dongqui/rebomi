# 지능형 검색 (search)

원본: PRD v0.5 §2.2 시나리오 B, §4.3, §5.2, §8(검색 아키텍처), §10(검색 지표), §11.3, §13 H1 · 공통 규칙: [architecture §5 흐름](../architecture.md#5-수집--처리--검색-흐름), [§9 기술](../architecture.md#9-확정-기술과-검증할-후보)

## 1. 목적

제목이나 정확한 키워드를 기억하지 못해도 저장한 콘텐츠를 찾게 한다. 목표는 AI가 답을 생성하는 것이 아니라 **저장한 원본을 정확히 찾아주는 것**이다. 검색은 wedge가 아니라 재노출의 약속을 지키는 필수 기반 기능이다.

## 2. 범위

**P0 포함**

| ID | 요구사항 |
| --- | --- |
| SRCH-1 | 키워드 검색: 제목, URL·도메인, AI 요약, 사용자 메모, 추출된 본문. 한국어(형태소·n-gram 대응)와 영어가 섞인 콘텐츠를 검색한다 |
| SRCH-2 | 의미 기반 검색: 자연어 문장의 의도와 내용이 비슷한 자료를 찾는다. 예: "스마트폰 중독을 줄이려고 앱을 잠그는 방법" → 앱 사용 제한, 스크린타임, 디지털 디톡스 자료 |
| SRCH-3 | 하이브리드 검색: 두 결과를 RRF로 결합한다. 의미적으로 관련된 자료를 우선하되 정확한 키워드 일치 자료도 적절히 상위에 둔다 |
| SRCH-4 | 결과 화면: 제목, 요약, 출처, 저장일, 매칭 근거(일치 키워드 또는 관련 문장), 추출 수준, 원문 열기, 보관/삭제 |
| SRCH-5 | 요약 생성 전 자료도 제목·URL로 검색된다 |
| SRCH-6 | 결과가 없으면 명확히 안내한다 |

**제외**

- 저장 문서 AI 챗봇 질의응답, 여러 문서를 종합한 AI 답변, 외부 웹 검색 통합 (MVP 제외, 챗봇은 P2)
- 고급 필터, 품질 개선·개인화 (P1)

## 3. 플랫폼별 역할

| 플랫폼 | 역할 |
| --- | --- |
| 서버 | 검색 API, 키워드·의미 질의, RRF 결합(`core`), 매칭 근거 생성 |
| 워커 | 임베딩 생성(청크 단위), 인덱싱 |
| 웹 | 검색 화면, 홈 상단 검색창(항상 노출) |
| 모바일 | 검색 화면 |
| 확장 | 없음 |

## 4. 사용자 흐름

1. 홈 상단 검색창이나 검색 화면에 단어 또는 자연어 문장을 입력한다.
2. 결과 목록에서 요약과 매칭 근거를 보고 원하는 자료를 고른다.
3. 원문을 열거나, 결과에서 바로 보관·삭제한다.

## 5. 동작 규칙과 예외

- 긴 본문은 청크로 나누어 임베딩하고, 매칭된 청크의 문장을 근거로 제시한다.
- 임베딩이 아직 없는 콘텐츠는 의미 검색에서 빠지지만 키워드 검색에는 나온다(SRCH-5).
- 검색 범위는 사용자 본인의 콘텐츠다. 휴지통 콘텐츠를 결과에 넣을지는 원문에 없다 — **[제안]** 제외한다.
- 보관됨 콘텐츠는 검색 대상이다. **[원문 §4.5]**
- 키워드 엔진과 임베딩 모델은 Phase 2에서 한·영 혼합 쿼리 100개로 비교 평가한 뒤 확정한다. 그 전까지 구현은 교체 가능하게 둔다.

## 6. 완료 조건

- [ ] 한국어 단어의 일부(예: 조사가 붙은 형태, 복합어의 일부)로 제목·본문·메모가 검색된다.
- [ ] 한 쿼리에 한국어와 영어가 섞여도 결과가 나온다.
- [ ] 제목·본문에 쿼리 단어가 하나도 없지만 뜻이 가까운 콘텐츠가 자연어 문장 쿼리로 검색된다.
- [ ] 정확한 키워드가 제목에 있는 콘텐츠가 의미만 가까운 콘텐츠에 밀려 사라지지 않는다.
- [ ] 각 결과에 매칭 근거(일치 키워드 또는 관련 문장)와 추출 수준이 표시된다.
- [ ] 방금 저장해 요약이 없는 콘텐츠가 제목·URL로 검색된다.
- [ ] 결과가 없을 때 빈 화면이 아니라 안내가 나온다.
- [ ] 다른 사용자의 콘텐츠는 어떤 쿼리로도 나오지 않는다.
- [ ] 결과에서 원문 열기, 보관, 삭제가 동작한다.
- [ ] 한·영 혼합 평가 쿼리 100개 세트와 평가 결과가 저장소에 기록된다 (Phase 2 게이트).
- [ ] 계측: 검색 실행, 결과 수, 결과 클릭(순위 포함), 재검색, 첫 클릭까지 시간이 기록된다 (H1, 검색 지표).
