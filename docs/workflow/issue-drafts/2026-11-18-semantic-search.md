### 1. 임베딩 모델과 호스팅

| 선택지 | 내용 | 비용 | 걸리는 것 |
| --- | --- | --- | --- |
| **(추천) bge-m3를 호스팅된 API로** | PRD의 후보 모델을 Cloudflare Workers AI로 부른다 | 입력 100만 토큰당 약 $0.012. 하루 무료 할당이 있다 | Cloudflare 계정과 API 토큰이 필요하다(사용자가 만든다). 본문이 Cloudflare로 나간다 |
| bge-m3를 직접 호스팅 | 추론 서버 컨테이너를 따로 띄운다 | 건당 비용 없음. 메모리 2GB 이상인 서버를 늘 켜 둔다 | 운영 부담. 로컬·CI에도 모델을 받아야 한다. 본문이 밖으로 나가지 않는다 |
| 다른 회사의 임베딩 API | 예: OpenAI `text-embedding-3-small` | 입력 100만 토큰당 약 $0.02 | PRD의 후보 모델이 아니다. 나중에 직접 호스팅으로 옮기면 전부 다시 임베딩한다 |

- 가격은 2026-11-18에 검색으로 확인한 값이다. 글 한 편을 3,000토큰으로 잡으면 1,300편에 약 $0.05~0.08이다.
- 추천 이유: 후보 모델 그대로 시작하고, 나중에 직접 호스팅으로 옮겨도 모델이 같아 검색 품질 비교가 쉽다. 서버를 늘 켜 둘 필요가 없다.
- 직접 호스팅 비용 어림(2026-11-18, 가격표를 다시 확인하지 않은 기억 기준 — 정할 때 확인한다):
  - bge-m3는 가중치만 약 2.3GB라 실제로는 메모리 4GB급이 편하다. 2GB는 양자화(ONNX int8 등)를 해야 맞는다.
  - 4GB급 CPU 서버를 늘 켜 두면 저가 VPS는 월 $5~10, 앱 플랫폼(Fly.io·Railway·Render 류)은 월 $20~30, 대형 클라우드의 4GB 인스턴스는 월 $25~35 수준이다. GPU는 월 수백 달러라 이 규모에서는 맞지 않는다.
  - 같은 돈을 API로 쓰면 월 $10에 약 8억 토큰(3,000토큰짜리 글 약 27만 편)이다. 그 아래에서는 API가 싸고, 직접 호스팅은 비용보다 "본문이 밖으로 나가지 않는다"가 이유가 된다.
  - CPU 추론은 느리다(청크 초당 몇 개 수준). 북마크 1,300개를 한 번에 가져오면 채우는 데 분~수십 분이 걸리고, 검색할 때 쿼리 임베딩에도 수십~수백 ms가 붙는다.
- 어느 쪽이든 임베딩 호출은 인터페이스 뒤에 두어 교체할 수 있게 한다. 자동 테스트는 가짜 구현으로 돌고 실제 호출은 하지 않는다.
- 외부 API를 쓰면 `architecture.md` §8의 "외부 AI로 본문을 보낼 때의 데이터 정책"을 적어야 한다.
